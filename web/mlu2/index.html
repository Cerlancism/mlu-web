Saved games

Saved games are kept in this browser. Export one to keep a copy or to move it to another browser; the file is the game's own .ml2 save file, so files from the original game can be imported too.

Snapshots

A snapshot keeps a whole game just as it was, taken with Take Snapshot in the game's Game menu while in a base or on the pause screen (M). Resume carries on from that moment; the saved games are not touched. Export one to keep a copy or to move it to another browser.
