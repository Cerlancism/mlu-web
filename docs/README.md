# mlu-web documentation

These documents describe the web ports of Motherload Unlimited, which can be played at <https://cerlancism.github.io/mlu-web/>.

| Game | Specification | Fixes |
|---|---|---|
| MLU 1, Shaken Snowglobe Edition | [mlu1/specifications.md](mlu1/specifications.md) | [mlu1/fixes.md](mlu1/fixes.md) |
| MLU 2: Crematoria | [mlu2/specifications.md](mlu2/specifications.md) | [mlu2/fixes.md](mlu2/fixes.md) |

A specification covers how its game behaves and how the web version is built. It is complete enough to rebuild the game from. The fixes document lists the bugs in the original game that the web version fixes. For each one it gives what the original did and what the web version does instead.
